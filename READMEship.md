# sodanhama portfolio
## description
I made this site with vanilla html css and js to serve as my github profile readme alongside my main portfolio website, as I wanted to get to express more through a single website.

I have majorly used CSS in this project without using JS at all, as of now. I have added sections for my skills, my learning plan, and my socials, along with my featured projects.

I have separated the entire content of the website from the body and added ASCII art of Rem in the background.
